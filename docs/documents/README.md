# Organizational documents (Track B)

The website is only half of the FIKRA project. This folder is the home for the
organizational documents, which run in parallel.

## Order and dependencies

Each document builds on the one before it, so they are drafted in this order:

| # | Document | Depends on | Review gate |
|---|---|---|---|
| B1 | Constitution | Founding/leadership brief | Leadership review + formal adoption |
| B2 | Strategic plan 2026–2028 | Adopted constitution | Leadership approval |
| B3 | Org chart | Strategic plan | Leadership approval |
| B4 | Staff handbook | Org chart | Leadership approval |

## Rules

- Every document carries a **version block**: version number, date, and status
  (Draft / In review / Adopted).
- Every draft opens with a **one-page executive summary** so leadership can
  review quickly.
- Adopted versions are **frozen as read-only PDFs** and archived; the editable
  source stays here.
- Each document has a **change log** recording what changed and when.
